# Tollgate Checklist — 阶段门检查清单

> 每次进下一阶段前跑一遍。**没签字 = 不进下一阶段**。

## Tollgate 1：D → M

**检查清单**：

- [ ] **项目章程已签字**（Sponsor / Champion / BB 三方签字）
- [ ] **SIPOC 完整**（5-7 步 + 5 元素齐全）
- [ ] **VOC/CTQ 树完成**（至少 3 个 CTQ 已量化 + 优先级排序）
- [ ] **项目计划已批准**（时间线 + 资源 + 沟通计划）
- [ ] **范围清晰**（In-Scope / Out-of-Scope 已写明）
- [ ] **目标 SMART**（具体 / 可量化 / 可达成 / 相关 / 有时限）
- [ ] **团队已组建**（RACI 已分）
- [ ] **风险已识别**（top 3 风险有应对）

**通过标准**：8/8 全过。任一项不过 → 留在 D 阶段补完。

---

## Tollgate 2：M → A

**检查清单**：

- [ ] **数据收集计划已批准**（含操作定义、抽样规则、样本量理由）
- [ ] **MSA 完成且通过**（GR&R < 30%，最好 < 10%）
- [ ] **基线数据已收集**（满足样本量 + 时间跨度）
- [ ] **数据已保存**（CSV / 数据库，可追溯）
- [ ] **过程能力已量化**（Cpk 基线值已记录）
- [ ] **数据分布已检查**（正态性 + 异常值处理）
- [ ] **控制图初稿**（过程稳定性初判：稳定 / 不稳定）
- [ ] **测量系统问题已解决**（若有）

**通过标准**：8/8 全过。

---

## Tollgate 3：A → I

**检查清单**：

- [ ] **根本原因已识别**（不是症状，有数据支撑）
- [ ] **鱼骨图完成**（6M 覆盖 + 团队工作坊产出）
- [ ] **5 Why 完成**（每个潜在根因至少 5 层追问）
- [ ] **假设检验结果明确**（p 值 + 效应大小 + 置信区间）
- [ ] **Pareto 已做**（关键少数已识别）
- [ ] **FMEA 完成**（关键失效模式有 RPN 评分）
- [ ] **根因确认**：团队 + Champion 达成共识
- [ ] **数据可视化**（让非技术人员也能看懂）

**通过标准**：8/8 全过。

---

## Tollgate 4：I → C

**检查清单**：

- [ ] **方案生成充分**（每根因至少 3 方案）
- [ ] **方案选择有依据**（多准则决策矩阵）
- [ ] **试点计划已批准**（地点 / 时间 / 样本 / 成功标准）
- [ ] **试点结果成功**（达到预期目标）
- [ ] **统计验证有效**（改进前后对比显著，p < 0.05）
- [ ] **Cpk 提升明显**（达到目标水平：≥ 1.33 工业 / ≥ 1.67 优秀）
- [ ] **方案可标准化**（文档化 + 可复制）
- [ ] **干系人认可**（流程负责人 + 团队 buy-in）

**通过标准**：8/8 全过。

---

## Tollgate 5：C → 结项

**检查清单**：

- [ ] **控制计划已发布**（含 KCP / 控制限 / 反应计划）
- [ ] **SPC 已上线运行**（≥ 4 周连续数据，无失控点）
- [ ] **文档已更新**（SOP / 作业指导书 / FMEA）
- [ ] **培训已完成**（运营团队 + 关键岗位）
- [ ] **收益已追踪 ≥ 1 个月**（财务验证 + 软性收益）
- [ ] **A3 报告已签字**（Champion / Sponsor）
- [ ] **项目移交**（给运营团队 owner）
- [ ] **经验教训已记录**（项目复盘 — 什么做得好 / 不好）

**通过标准**：8/8 全过。

---

## 通用的检查动作

每次跑 tollgate 时：

1. 复制对应 checklist 到 `state.json` 的 tollgates 段
2. 逐项打勾 / 列出缺什么
3. 输出：`✅ Tollgate X 通过` 或 `⚠️ 缺 X / Y / Z，留在当前阶段`
4. 通过后更新 `state.json` 的 `phase` + `tollgates.X.passed = true` + `checked_at`
5. 通知 Champion 签字

---

**模板引用**：state.json 中的 tollgates 结构：
```json
"tollgates": {
  "d_to_m": {"passed": false, "checked_at": null, "notes": ""},
  ...
}
```
