## 多准则决策矩阵

### 评分标准

| 准则 | 权重 (1-10) | 1 分 | 5 分 | 10 分 |
|---|---|---|---|---|
| **效果**（对 CTQ 影响） | | 几乎无效 | 中等 | 显著 |
| **可行性**（技术成熟度） | | 不成熟 | 部分成熟 | 完全成熟 |
| **成本**（实施成本） | | 高 | 中 | 低 |
| **实施时间** | | > 6 月 | 3-6 月 | < 1 月 |
| **风险**（副作用 / 失败风险） | | 高 | 中 | 低 |
| **可持续性**（长期可维持） | | 难 | 中 | 易 |
| **干系人支持** | | 反对 | 中立 | 强烈支持 |

> **注意**：成本 / 风险等"差"的指标，要反向记分（高分=好），避免混淆。
