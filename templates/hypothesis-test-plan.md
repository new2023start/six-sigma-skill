## 检验方法选择

| 场景 | 检验方法 | stats.py 命令 |
|---|---|---|
| 1 组 vs 已知值（连续） | 单样本 t 检验 | `ttest --mode one` |
| 2 组 vs 2 组（连续，正态） | 双样本 t 检验 | `ttest --mode two` |
| 配对数据（前 / 后） | 配对 t 检验 | `ttest --mode paired` |
| 方差不齐 | Welch t 检验 | `ttest --mode welch` |
| 2 组 vs 2 组（属性） | 卡方检验 | `chi2` |
| 比例 vs 已知值 | 比例检验 | `proportion` |
| 3+ 组（连续） | 单因素 ANOVA | `anova` |
| 多因子 | 因子 ANOVA | `anova --factor` |
| 非正态 | Mann-Whitney / Kruskal-Wallis | `mann-whitney` / `kruskal` |
| 正态性检验 | Shapiro-Wilk / Anderson-Darling | `normality` |
