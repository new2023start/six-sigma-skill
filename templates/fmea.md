# FMEA — 失效模式与影响分析

> A / I 阶段。识别潜在失效、评估风险、确定优先级。

## 评分标准

### 严重度 S（Severity）— 1-10
| S | 描述 |
|---|---|
| 10 | 安全 / 法规灾难，无警告 |
| 9 | 安全 / 法规灾难，有警告 |
| 8 | 主要失效，丧失主要功能 |
| 7 | 主要性能下降 |
| 6 | 次要功能丧失 |
| 5 | 次要性能下降 |
| 4 | 客户轻微不满 |
| 3 | 客户发现但接受 |
| 2 | 仅敏锐客户发现 |
| 1 | 无影响 |

### 频度 O（Occurrence）— 1-10
| O | 描述 | 失败率 |
|---|---|---|
| 10 | 非常高，几乎必现 | ≥ 1/2 |
| 9 | 非常高 | 1/3 |
| 8 | 高 | 1/8 |
| 7 | 高 | 1/20 |
| 6 | 中高 | 1/80 |
| 5 | 中 | 1/400 |
| 4 | 中 | 1/2,000 |
| 3 | 低 | 1/15,000 |
| 2 | 低 | 1/150,000 |
| 1 | 极低 | ≤ 1/1,500,000 |

### 探测度 D（Detectability）— 1-10
> D 越高 = 越难探测到。**注意：D 与 S、O 反向**

| D | 描述 |
|---|---|
| 10 | 绝对不确定，无探测机制 |
| 9 | 很罕见能探测 |
| 8 | 仅偶尔探测 |
| 7 | 低探测能力 |
| 6 | 中低探测能力 |
| 5 | 中等探测能力 |
| 4 | 中高探测能力 |
| 3 | 高探测能力 |
| 2 | 很高探测能力 |
| 1 | 几乎肯定能探测（自动防错） |

### RPN = S × O × D
> RPN 越高越优先处理。一般 > 100 或 S ≥ 9 优先
