## 1. 测量目标

## 2. 操作定义（Operational Definition）

> 把模糊的 CTQ 变成**所有人都能一致测量**的指标。

| 维度 | 操作定义 |
|---|---|
| **测什么** | <具体物理量 / 属性> |
| **单位** | <mm / °C / ppm / % / 件> |
| **测量工具** | <卡尺 / 三坐标 / 目视 / 软件> |
| **量具精度** | <0.01mm / 0.1°C> |
| **测量方法** | <具体步骤：取样位置 / 测量次数 / 读数方式> |
| **环境条件** | <温度 / 湿度 / 振动> |
| **校准要求** | <校准频率 + 标物> |
| **通过 / 不通过判据** | <USL / LSL / 抽样方案> |

## 3. 数据类型

- **类型**：连续型 / 离散型（属性）
  - 连续：尺寸、重量、温度、时间
  - 属性：合格 / 不合格、缺陷类型

## 4. 抽样方案

| 项目 | 内容 |
|---|---|
| **抽样方法** | 简单随机 / 系统抽样 / 分层抽样 / 整群抽样 |
| **抽样频率** | 每小时 / 每批 / 每天 / 每周 |
| **样本量（每次）** | <N> |
| **采样总次数** | <N> |
| **总样本量** | <N × N> |
| **样本量理由** | <样本量计算结果，如 "mean: delta=0.5, sigma=1, alpha=0.05, power=0.8 → n=32"> |
| **采样地点** | <工位 / 工序 / 客户现场> |
| **采样人** | <操作员 / QA / 自动采集> |

### 样本量计算（参考）

```bash
# 连续型（mean）
python scripts/stats.py sample-size mean --delta 0.5 --sigma 1.0 --alpha 0.05 --power 0.8

# 比例（proportion）
python scripts/stats.py sample-size proportion --p0 0.05 --p1 0.03 --alpha 0.05 --power 0.8
```
